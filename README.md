# 🐶 DogsVPN — ربات هوشمند تلگرامی (رایگان + فروشگاه VIP)

نسخه جدید و کامل ربات **DogsVPN** با ترکیب دوگانه: **کانفیگ‌های رایگان استخر زنده + فروشگاه اشتراک VIP اختصاصی**.

---

## ✨ امکانات کامل

### 🛒 ۱. فروشگاه اشتراک VIP
- 💎 **پلن‌های متنوع:**
  - ۳۰ روزه ۵۰ گیگ (۱۴۹,۰۰۰ تومان)
  - ۳۰ روزه ۱۰۰ گیگ محبوب (۲۱۹,۰۰۰ تومان)
  - ۶۰ روزه ۲۰۰ گیگ (۳۸۹,۰۰۰ تومان)
  - ۹۰ روزه نامحدود VIP (۵۴۹,۰۰۰ تومان)
- 🌍 **۸ لوکیشن پرسرعت و اختصاصی:** 🇩🇪 آلمان، 🇳🇱 هلند، 🇫🇷 فرانسه، 🇺🇸 آمریکا، 🇬🇧 انگلیس، 🇹🇷 ترکیه، 🇨🇦 کانادا، 🇯🇵 ژاپن
- ⚡ **پروتکل‌های نسل جدید:** VLESS Reality / VMess / Trojan / Shadowsocks
- 💳 **روش‌های پرداخت چندگانه:**
  - کارت به کارت با ارسال تصویر فیش برای ادمین
  - پرداخت آنی از کیف پول
  - پرداخت ارزی تتر (USDT TRC20)

### 🎁 ۲. بخش رایگان و تست
- 🆓 دریافت فوری کانفیگ رایگان زنده (VLESS / VMess / Trojan / Shadowsocks) با پینگ خودکار
- ⚡ تست رایگان ۲ روزه VIP برای تمام کاربران جدید
- 🔗 لینک سابسکریپشن هوشمند (Subscription Link) جهت افزودن به کلاینت‌ها

### 💰 ۳. کیف پول و سیستم رفرال
- 👛 مدیریت و مشاهده موجودی کیف پول
- 💳 افزایش موجودی با کارت به کارت
- 👥 سیستم دعوت دوستان (زیرمجموعه‌گیری) با پاداش نقدی خودکار به کیف پول

### 👑 ۴. پنل مدیریت پیشرفته (Admin)
- دستور `/admin` برای ادمین
- 📋 تایید یا رد فیش‌های واریزی کارت به کارت همراه با تصویر فیش
- 📢 ارسال پیام همگانی (Broadcast) به تمام کاربران ربات
- 💳 تغییر شماره کارت و نام صاحب حساب مستقیماً از ربات
- 💰 شارژ مستقیم کیف پول هر کاربر با آیدی عددی
- 📊 مشاهده آمار کل کاربران، سفارشات و درآمد

### 🌐 ۵. وب‌سرور و اشتراک
- صفحه لندینگ مدرن با وضعیت زنده سرورها و آمار کاربران
- روت `/sub/:uuid` برای اتصال مستقیم نرم‌افزارهای v2rayNG / Streisand / Hiddify / V2Box
