# 🎬 ربات دانلودر همه‌کاره (Telegram)

ربات تلگرامی که از **یوتیوب، اینستاگرام، تیک‌تاک، توییتر/ایکس، فیسبوک، ردیت،
تلگرام و (اختیاری) روبیکا** — به‌علاوه‌ی صدها سایت دیگر — ویدیو و صدا دانلود می‌کند.

فقط لینک را بفرست؛ ربات خودش پلتفرم را تشخیص می‌دهد و فایل را برمی‌گرداند. 🚀

---

## ✨ امکانات

- ▶️ **یوتیوب** — ویدیو یا صدا (mp3)
- 📸 **اینستاگرام** — پست، ریلز، IGTV
- 🎵 **تیک‌تاک** — ویدیو بدون واترمارک
- 🐦 **توییتر / ایکس** — ویدیو و GIF
- 📘 **فیسبوک** و **ردیت** و پست‌های عمومی **تلگرام**
- 🟡 **روبیکا** — (اختیاری، نیازمند اکانت)
- 🌐 هر سایت دیگری که `yt-dlp` پشتیبانی کند

## 🕹️ دستورها

| دستور | توضیح |
|---|---|
| `/start` | شروع و راهنما |
| `/help` | راهنمای کامل |
| `/mp3 <لینک>` | دانلود فقط صدا (MP3) |
| `/video <لینک>` | دانلود ویدیو |
| `/yt <لینک>` | یوتیوب |
| `/insta <لینک>` | اینستاگرام |
| `/tiktok <لینک>` | تیک‌تاک |
| `/rubika <لینک>` | روبیکا |

کافی است لینک را **مستقیم** بفرستی — تشخیص خودکار است.

---

## 🛠️ نصب و اجرا

### پیش‌نیازها
- Python 3.9+
- [FFmpeg](https://ffmpeg.org) (برای ادغام ویدیو/صدا و تبدیل mp3)

### مراحل
```bash
cd downloader-bot

# ۱) محیط مجازی
python3 -m venv venv
source venv/bin/activate        # ویندوز: venv\Scripts\activate

# ۲) نصب وابستگی‌ها
pip install -r requirements.txt

# ۳) تنظیم توکن
cp .env.example .env
# سپس BOT_TOKEN را در .env قرار بده

# ۴) اجرا
python bot.py
```

### نصب FFmpeg
- **Ubuntu/Debian:** `sudo apt install ffmpeg`
- **macOS:** `brew install ffmpeg`
- **Windows:** از [ffmpeg.org](https://ffmpeg.org/download.html) دانلود کن

## 🟡 تنظیم روبیکا (اختیاری)

روبیکا لینک عمومیِ مستقیم فایل نمی‌دهد؛ برای دانلود به یک اکانت روبیکا نیاز است:

```bash
pip install -U rubpy
```

سپس در `.env` یکی از این دو حالت:

```ini
# حالت ۱: با auth key
RUBIKA_AUTH=your_auth_key

# حالت ۲: با شماره موبایل و رمز
RUBIKA_PHONE=09123456789
RUBIKA_PASSWORD=your_password
```

> ⚠️ بخش روبیکا به دلیل تغییرات مکرر API و کتابخانه، «آزمایشی» است و ممکن است
> نیاز به تنظیم بر اساس نسخه‌ی نصب‌شده داشته باشد. بقیه‌ی پلتفرم‌ها مستقل کار می‌کنند.

## ⚙️ متغیرهای محیطی

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `BOT_TOKEN` | — | توکن ربات از @BotFather |
| `ADMIN_IDS` | — | آیدی ادمین‌ها (کاما جدا) |
| `MAX_FILE_SIZE_MB` | `49` | حداکثر حجم ارسال فایل |
| `RUBIKA_AUTH` | — | auth key روبیکا |
| `RUBIKA_PHONE` | — | شماره اکانت روبیکا |
| `RUBIKA_PASSWORD` | — | رمز اکانت روبیکا |

## 🐳 اجرا با Docker

```bash
docker build -t downloader-bot .
docker run --env-file .env downloader-bot
```

## ☁️ استقرار

## 📝 نکته‌ها

- حد مجاز آپلود ربات تلگرام **۵۰ مگابایت** است (در این پروژه پیش‌فرض ۴۹ MB).
- برای ویدیوهای بزرگ، از `/mp3` استفاده کن (حجم کمتر).
- برخی سایت‌ها ممکن است به دلیل محدودیت جغرافیایی یا ورود اجباری، دانلود نشوند.
