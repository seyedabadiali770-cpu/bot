# 🎪 سرگرمی بات

ربات تلگرامی سرگرمی فارسی — جوک، فال حافظ، بازی و خنده!

## ✨ امکانات

| دستور / دکمه | کارش |
|---|---|
| `/menu` | منوی بازی‌ها |
| 😂 `/joke` | جوک خنده‌دار فارسی |
| 📖 `/fal` | فال حافظ با تعبیر |
| 🎰 `/slot` | اسلات شانس (امتیاز داره!) |
| 🔢 `/guess` | بازی حدس عدد (۳ شانس) |
| 🪙 `/coin` | شیر یا خط |
| 🎲 `/dice` | تاس شانس |
| ⭐ `/me` | امتیاز، سطح و رتبه تو |
| 🏆 `/top` | برترین کاربران |

## ⭐ سیستم امتیاز و سطح

- هر بازی امتیاز داره؛ جک‌پات اسلات ۵۰ امتیاز، شیش آوردن تاس ۱۰ امتیاز
- رتبه‌ها: 🐣 تازه‌وارد → 😊 مشتری پروپاقرص → 😎 حرفه‌ای → 🔥 قهرمان → 👑 اسطوره
- امتیازها روی گیتهاب ذخیره می‌شن و پاک نمی‌شن

## 🚀 اجرا

```bash
cd fun-bot
npm install
node index.js
```

متغیر محیطی `FUN_BOT_TOKEN` (توکن ربات از @BotFather) — اگه نباشه از توکن پیش‌فرض استفاده می‌کنه.

## 🌍 استقرار ۲۴ ساعته

ربات سرگرمی کنار ربات اصلی (DogsVPN) خودکار روشن می‌شه:
فایل `index.js` ریشه، این ربات رو به‌عنوان زیرفرایند اجرا می‌کنه،
پس همون workflow فعلی گیت‌هاب (`Run VPN Bot`) هر دو ربات رو هم‌زمان نگه می‌داره.
امتیازها در `data/fun-users.json` ذخیره می‌شن و مثل بقیه دیتاها خودکار push می‌شن.
