# 🎨 پرامپت عکس بات — ربات کانال پرامپت تصویرسازی هوش مصنوعی

ربات تلگرامی که **خودش کانال را تشخیص می‌دهد** و هر ساعت یک **پرامپت عکس آماده** — همراه با **عکس نمونه‌ی ساخته‌شده با همان پرامپت** — در کانال منتشر می‌کند.

> پرامپت‌ها انگلیسی و آماده‌ی کپی‌اند (مناسب Arena، Midjourney، Flux، DALL·E، Stable Diffusion) و زیر هر پست یک نکته‌ی فارسی برای شخصی‌سازی پرامپت نوشته می‌شود.

---

## ⚡️ راه‌اندازی در ۴ قدم

### ۱) ساخت ربات
در تلگرام به [@BotFather](https://t.me/BotFather) پیام بده → `/newbot` → اسم و یوزرنیم بده → **توکن** را کپی کن.

### ۲) دادن توکن به پروژه

| محیط | کار |
|---|---|
| **GitHub Actions** (همین ریپو) | `Settings → Secrets and variables → Actions → New repository secret` — نام: `PROMPT_BOT_TOKEN`، مقدار: توکن. اختیاری: `PROMPT_ADMIN_ID` (آیدی عددی خودت) |
| **Railway / Render / VPS** | متغیر محیطی `PROMPT_BOT_TOKEN` را ست کن |

### ۳) اضافه‌کردن ربات به کانال (مهم)
ربات را در کانالت اضافه کن و **ادمین** کن با اجازه‌ی **Post Messages**.
همین که ادمینش کنی، ربات خودش پیام «فعال شد» می‌فرستد و **از همان لحظه هر ساعت شروع به پست‌کردن می‌کند** — بدون هیچ تنظیم اضافه‌ای.

> نکته: اگر کانالت خصوصی است، ادمین‌کردن ربات کافی است؛ نیازی به آیدی عددی نیست. اگر خواستی دستی کانال را قفل کنی، متغیر `PROMPT_CHANNEL_ID` را با آی‌دی کانال (`-100...`) ست کن.

### ۴) چت خصوصی با ربات
به ربات `/start` بده تا **پنل مدیریت** باز شود.

---

## 🎛 پنل مدیریت (چت خصوصی)

| دکمه / دستور | کار |
|---|---|
| 📮 پست فوری در کانال | همین حالا یک پرامپت + عکس در کانال بگذار |
| 👀 پیش‌نمایش | پست بعدی را ببین، بدون ارسال |
| ⏱️ بازه‌ی زمانی | هر ۱۵ دقیقه تا هر ۶ ساعت (پیش‌فرض: هر ۶۰ دقیقه) |
| 🗂️ دسته‌بندی‌ها | انتخاب چند دسته (پرتره، انیمه، لوگو، ایرانی، غذا، …) |
| 🖼️ عکس نمونه | روشن/خاموش کردن ساخت و ارسال عکس |
| 🤖 هوش مصنوعی | تولید پرامپت تازه با API (در صورت ست‌بودن `AI_API_KEY`) |
| ⏸ / ▶️ | توقف موقت و ادامه‌ی ارسال |

دستورهای متنی: `/postnow`، `/preview`، `/interval 30`، `/categories`، `/pause`، `/resume`، `/ai on|off`، `/image on|off`، `/addprompt`، `/stats`، `/channel`، `/help`

نمونه‌ی افزودن پرامپت خودت:
```
/addprompt عنوان فارسی | نکته یا ایده‌ی تغییر | the full English prompt here, cinematic light, 8k
```
(اگر بدون `|` بنویسی، فقط پرامپت انگلیسی ثبت می‌شود.)

## 🧠 محتوا از کجا می‌آید؟

- **بانک داخلی:** ۱۲۵ پرامپت حرفه‌ای در ۲۴ دسته‌بندی → `prompt-bot/prompts.js`
- **تولید خودکار با AI (اختیاری):** با ست‌کردن کلید، بخشی از پست‌ها (پیش‌فرض ۳۵٪) پرامپت تازه می‌شوند:

| متغیر | پیش‌فرض | توضیح |
|---|---|---|
| `AI_API_KEY` | — | کلید هر سرویس سازگار با OpenAI (OpenAI، Groq، OpenRouter…) |
| `AI_BASE_URL` | `https://api.openai.com/v1` | آدرس سرویس |
| `AI_MODEL` | `gpt-4o-mini` | نام مدل |
| `PROMPT_AI_RATIO` | `0.35` | سهم پست‌های تولیدشده با AI (۰ تا ۱) |

## 🖼 عکس نمونه چطور ساخته می‌شود؟

۱. اگر `OPENAI_API_KEY` ست باشد → عکس با `gpt-image-1` ساخته می‌شود.
۲. در غیر این صورت → از سرویس رایگان **Pollinations** (مدل Flux، بدون نیاز به کلید).
۳. اگر ساخت عکس شکست بخورد یا `PROMPT_IMAGE=off` باشد → پست **متنی** ارسال می‌شود (ربات هرگز متوقف نمی‌شود).

| متغیر | پیش‌فرض |
|---|---|
| `PROMPT_IMAGE` | `on` (`off` = پست فقط متنی) |
| `PROMPT_IMAGE_WIDTH` / `PROMPT_IMAGE_HEIGHT` | `1024` |
| `POLLINATIONS_MODEL` | `flux` |
| `POLLINATIONS_BASE` | `https://image.pollinations.ai` |

---

## ⏱ چرا «هر ساعت» روی GitHub Actions هم درست کار می‌کند؟

ورک‌فلوی `Run VPN Bot` هر ۶ ساعت اجرا می‌شود و هر اجرا تا **حدود ۶ ساعت** زنده می‌ماند؛ پس عملاً همیشه یک نسخه‌ی ربات در حال اجراست. زمان‌بند داخلی با ذخیره‌ی `lastPostedAt` در `data/prompt-bot.json` (که خودکار در گیت commit می‌شود) **شکاف‌ها را جبران می‌کند**: اگر اجرا قطع شده باشد، اجرای بعدی منتظر نمی‌ماند و بلافاصله پست عقب‌افتاده را می‌گذارد.

## 🧪 تست محلی (بدون توکن و بدون اینترنت)

یک شبیه‌ساز Telegram Bot API در `test/telegram-mock.js` هست که همان رفتار واقعی را دارد:

```bash
cd /path/to/bot
npm install                                   # نصب telegraf در ریشه
node prompt-bot/test/smoke-test.js            # اجرای ۲۹ تست سرتاسری
```

شبیه‌ساز به‌تنهایی هم قابل اجراست (مثلاً برای تست دستی روی پورت ۸۰۴۳):
```bash
node prompt-bot/test/telegram-mock.js 8043
PROMPT_BOT_TOKEN=1:test TELEGRAM_API_ROOT=http://127.0.0.1:8043 node prompt-bot/index.js
```

## 🩺 عیب‌یابی سریع

| مشکل | راه‌حل |
|---|---|
| پستی نمی‌آید | در کانال، ربات را **ادمین** کن (اجازه‌ی Post Messages) و `/status` بزن تا کانال و زمان پست بعدی را ببینی |
| «chat not found» | ربات را از کانال حذف و دوباره ادمین کن؛ یا `PROMPT_CHANNEL_ID` را درست بده |
| عکس ساخته نمی‌شود | `PROMPT_IMAGE=off` نیست؟ سرویس Pollinations گاهی شلوغ است؛ ربات خودکار پست متنی می‌فرستد |
| فقط به ادمین جواب می‌دهد | این رفتار عمدی است؛ برای تغییر، `PROMPT_ADMIN_ID` را عوض کن |
