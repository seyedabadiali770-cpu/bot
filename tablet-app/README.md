# ⭐ ستاره لایو (StarLive)

اپلیکیشن سرگرمی فارسی مخصوص تبلت‌های قدیمی اندروید — ساخته و تست‌شده برای **Lenovo Tab 2 A7-30HC** (اندروید ۴.۴ کیت‌کت، ۱ گیگ رم، صفحه ۱۰۲۴×۶۰۰).

## امکانات

| بخش | توضیح |
|---|---|
| 💬 چت با ستاره‌ها | گفتگوی فارسی با رونالدو، مسی، طارمی، رونالدینیو، مربی انگیزشی، رفیق فابریک، فالگیر و ستاره پاپ. کاملاً آفلاین (بدون اینترنت و بدون API) |
| ⚡ پیام‌های آماده | برای هر شخصیت چند پیام آماده (پرمچرد) که با یک ضربه ارسال می‌شن |
| 🎙 استیکر و ویس | ۳۰ استیکر + پیام صوتی شبیه‌سازی‌شده + تیک دوتایی و «در حال نوشتن...» |
| 📞 تماس زمان‌بندی‌شده | تعیین ساعت دقیق، تکرار روزانه، تماس صوتی/تصویری و حتی جمله‌ای که ستاره موقع تماس می‌گه. با **AlarmManager** اندروید حتی وقتی برنامه بسته‌ست زنگ می‌خوره |
| 📡 لایو اینستاگرامی | بیننده‌های میلیونی، کامنت‌های زنده فارسی، قلب‌های پرنده، هدیه (گل، تاج، الماس، موشک)، جواب دادن میزبان به کامنت شما، آمار پایان لایو |
| 🔴 لایو خودم | خودت لایو بذار، بیننده و هدیه بگیر و فالوور اضافه کن |
| 🔮 آینه‌های جادویی | شغل آینده، همسر آینده، سن ازدواج، ثروت، تعداد فرزند، شخصیت‌شناسی، درصد عشق، فال حافظ، طالع و شانس روز، چهره ۲۰ سال بعد، شبیه‌ترین ستاره — همه با اسکنر اثر انگشت |
| 🕵️ دروغ‌سنج حسگری | با داده‌ی **واقعی** حسگرها (پایین‌تر توضیح داده شده) |

| ⚙ تنظیمات | تم روشن/تاریک، صدا، لرزش، خاموش کردن جلوه‌ها برای تبلت‌های ضعیف، قفل اثر انگشت |

## 🕵️ دروغ‌سنج چطور «واقعی» است؟

این تبلت حسگر اثر انگشت و ضربان‌سنج ندارد، اما این‌ها واقعاً اندازه‌گیری می‌شوند:

1. **زمان واکنش** — فاصله بین نمایش سؤال و لحظه‌ی پاسخ (میلی‌ثانیه)
2. **لرزش دست** — انحراف معیار شتاب‌سنج تبلت در حین پاسخ
3. **فشار و سطح تماس انگشت** — از `MotionEvent.getPressure()` و `getSize()` اندروید
4. **بی‌ثباتی صدا** — RMS میکروفون با `AudioRecord` هنگام جواب دادن بلند

ابتدا با ۳ سؤال کنترلی **کالیبراسیون** انجام می‌شود (حالت عادی بدن شما)، سپس هر پاسخ به‌صورت z-score نسبت به همان پایه سنجیده و با وزن‌دهی ترکیب می‌شود. نتیجه علمیِ قطعی نیست (هیچ دروغ‌سنج موبایلی نیست) اما اعداد واقعی و از خود حسگرها هستند، نه تصادفی.

## ساخت APK

APK به‌صورت خودکار با GitHub Actions ساخته می‌شود (`.github/workflows/build-apk.yml`) و در بخش **Releases** و **Artifacts** قرار می‌گیرد.

ساخت دستی روی سیستمی که Android SDK و JDK دارد:

```bash
export ANDROID_HOME=/path/to/android-sdk
bash tablet-app/scripts/build-apk.sh
# خروجی: tablet-app/build/StarLive.apk
```

بیلد بدون Gradle انجام می‌شود (`aapt2` → `javac` → `d8` → `zipalign` → `apksigner`) تا سریع و بدون وابستگی باشد.

## اجرا بدون نصب (تست سریع)

```bash
cd tablet-app/www && python3 -m http.server 8080
```
سپس در مرورگر تبلت آدرس `http://IP:8080` را باز کنید.

## نصب روی تبلت

1. فایل `StarLive.apk` را دانلود کنید
2. در تبلت: تنظیمات ← امنیت ← «منابع ناشناس» را روشن کنید
3. فایل را باز و نصب کنید

## سازگاری

- `minSdkVersion 19` (اندروید ۴.۴) — `targetSdkVersion 22` (بدون مجوزهای زمان اجرا)
- کد جاوااسکریپت کاملاً **ES5** و CSS بدون `grid` / `gap` / `var()` تا در WebView کروم ۳۳ درست کار کند
- بدون فریم‌ورک، بدون فونت وب، بدون درخواست شبکه — حجم کم و اجرای روان روی ۱ گیگ رم
